# <RuleFile 標題：一句話講這支規則檔管哪個領域的對錯>

## Rule 1 — <判準標題：主詞 + 必須／應／不得 + 單一條件>

- <descriptions：至少一句平鋪散文，講清楚「要看什麼、為什麼這樣對、踩到的因果」。可多句、可多個列表項，但不用粗體斜體。>
- <選用 標籤: 需要帶出對照表或範本時，用一行「標籤: 」起頭，下一行接 markdown 表格字串或範本字串>

### Good

情境: <一句具體情境>

<具體 example data：程式碼、路徑、輸出片段或一段帶真實資料的描述，要看得到，不是抽象話>

結果: <選用，這樣做帶來什麼好結果>

### Bad

情境: <選用，一句具體情境>

<具體壞例 data：看得到的錯誤片段>

結果: <選用，這樣做會壞在哪>

預期改法:

- <針對上面這個壞例的最小、對症修正動作；不是把 Good 整段複製過來>
