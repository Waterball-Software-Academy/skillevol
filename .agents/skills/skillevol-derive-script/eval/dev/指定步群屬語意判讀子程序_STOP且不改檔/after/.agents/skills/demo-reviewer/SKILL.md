# Purpose

根據 eval failure 決定是直接修正、還是先升級成 design 討論。

# SOP

1. read 最新的 `eval-report.md`。
2. think 判斷 failure 是否屬於 design conflict。
3. think 若屬 design conflict，決定要 escalate 還是直接修。
4. write 對使用者的建議與下一步。
