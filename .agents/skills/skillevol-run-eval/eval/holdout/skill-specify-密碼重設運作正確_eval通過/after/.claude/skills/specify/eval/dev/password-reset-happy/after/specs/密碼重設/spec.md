# 密碼重設

使用者忘記密碼時可以透過 email 要求重設密碼；重設連結 15 分鐘有效、一次性，使用後立即失效。

## 驗收標準

### 申請重設連結
- Given 使用者「林小美」已註冊，email 為 `mei@example.com`
- When 使用者在 `/forgot-password` 輸入 `mei@example.com` 並送出
- Then 系統寄出重設密碼信，頁面顯示「重設連結已寄出，請檢查信箱」

### 使用有效連結重設
- Given 使用者「林小美」在 15 分鐘內開啟尚未使用的重設連結
- When 使用者輸入新密碼 `NewPass1234` 並送出
- Then 系統更新密碼、使該連結立即失效，並導向 `/login`

### 連結過期或已使用
- Given 重設連結已超過 15 分鐘或已被使用過
- When 使用者開啟該重設連結
- Then 系統顯示「重設連結已失效，請重新申請」

# 澄清 Q&A

## Q1: 重設密碼連結要如何限制有效性？
- Answer: 連結 15 分鐘有效、一次性，使用後立即失效。
