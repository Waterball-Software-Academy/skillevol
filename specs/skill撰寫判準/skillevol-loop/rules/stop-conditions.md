# 停止條件規則

本檔只規範報告證據不足或使用者需求越界時，loop 何時必須停止。

## Rule 1 — 報告證據不足或需求越界時必須停止

- 若測試報告沒有指出哪個檔案、步驟、規則或產物出錯，不得猜測要改哪裡。
- 若使用者要求超出目標 skill 的公開責任範圍，不得自行擴權。
- 停止回報要列出卡住原因、缺少的證據，以及應回到哪個上游 skill 或哪份測試報告。

### Good

情境: 評分報告只說「結果不佳」，沒有定位到檔案、步驟、規則或產物。

```
停止: 測試報告沒有指出違規位置，無法選擇修改範圍。
下一步: 補強 expect 或 eval-report，使報告指出違規位置。
```

結果: loop 沒有用猜測擴大修改面。

### Bad

情境: 報告證據不足。

```
我猜可能是 SOP 不夠詳細，所以先把 SOP 補長。
```

結果: 以猜測取代失敗分析，常導致 instruction bloat。

預期改法:

- 停止並要求補足測試報告的違規定位；不得進入修改選擇。
